# Proposal

## Why

现有功能分散在 README、各端说明和源码中，读者难以快速了解系统能力及平台限制。需要一份有依据的中文功能总览，便于使用者和后续维护者查阅。

## What Changes

- 在 `docs/` 新增当前功能总览，记录学习流程、学习管理、激励机制和各端差异。
- 区分现有功能、已知限制和路线图待办，对资源规模标明版本及来源。
- 从 README 提供文档入口，并核对关键描述与源码、已有文档一致。
- 不改变产品行为、数据、接口或部署方式。

## Capabilities

### New Capabilities

无；本变更只记录现有行为，不新增产品要求。

### Modified Capabilities

无；不改变现有产品要求。此纯文档变更跳过 delta specs。

## Impact

涉及 `docs/` 中的功能文档与 README 导航；不影响应用代码、依赖或用户数据。
