# Proposal

## Why

目前孩子档案只显示四种动物 Emoji，家长和管理员没有头像，排行榜也没有统一的头像展示。提供内置 Canvas 头像及明确的修改入口，让三类用户在资料、学习和排名中保持一致、可辨认的身份。

## What Changes

- 增加统一的内置头像目录与 Canvas 2D 绘制组件，首期默认 16 款；保留 `panda`、`fox`、`rabbit`、`bear` 四个已有 ID。
- 孩子、家长和管理员均可预览、选择、保存自己的头像；家长可继续为本家庭孩子选头像，家长代入时显示当前孩子头像。
- 学生登录账号与其绑定档案共享唯一头像来源，不分别维护两份头像；学生的头像修改权限不扩大为家庭资料编辑权限。
- 头像按稳定 ID 保存到服务端，提供白名单验证、并发版本检查、刷新与跨设备读取及身份切换后的界面清理。
- 将头像统一接入账号区、孩子档案与总览、学习首页和现有模拟联赛；自己使用所选头像，影子同学按稳定身份分配头像，不随排名变化。
- 保留模拟联赛标识、原 XP/名次/奖励规则；不引入真实跨家庭排行榜、图片上传、自由绘画编辑器或付费头像。
- 不改变 M1 的未完成录音验收记录，不包含 M2 知识诊断、安卓站点切换或原生客户端重写。

## Capabilities

### New Capabilities

- `preset-avatars`: Canvas 头像目录、统一绘制、三角色与孩子模式的头像归属、选择保存、并发及兼容。
- `league-avatar-display`: 模拟联赛本人及影子同学头像的一致、稳定展示，并维持原排名和奖励语义。

### Modified Capabilities

无。当前 `openspec/specs/` 为空；M1 的 `student-profiles` 等仍是未归档变更中的 delta。本变更补充头像能力，不复制或重写 M1 的完整档案权限规格；未来同步需与其保持兼容。

## Impact

涉及 `apps/api/app/{auth,students,learning,portability}`、一项增量数据库迁移、`apps/web/src/components/{account,learning}`、`apps/web/src/app/learn/page.tsx` 及新的头像目录/组件。接口增加登录主体头像读写和受限的孩子模式头像更新，联赛行增加头像字段；扩展家庭导出中的非敏感头像信息。复用现有认证、CSRF、学生范围及 revision 机制，不增加图片存储或外部依赖。云端页面及加载该站点的 WebView 共用展示；原 local 模式仅做兼容回归，不新增离线账号头像体系。
