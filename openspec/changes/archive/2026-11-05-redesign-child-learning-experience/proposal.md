# Proposal

## Why

当前云端儿童页沿用管理表单的控件和长列表：390px 首屏重复展示头像编辑、退出和奖励消费入口，第一个课程操作约在页面 1737px 处，孩子难以直接开始学习。用户已选择“熊猫森林探险”，需要统一卡通视觉、手机信息层级及声音反馈，并在代码实现前确认视觉稿。

## What Changes

- 先提供同一森林主题下的三份手机首页视觉稿，经用户选择后再实现；明确选择前只进行取景、素材与设计工作。
- 统一奶油白、嫩绿、天蓝的绘本森林语言、熊猫伙伴、背景插画、字体、卡片、按钮与状态，覆盖儿童首页、课程/挑战/复习、答题、故事/听读、排行、商店与我的；登录、家长和管理员页面采用同源视觉规范。
- 儿童首屏呈现紧凑身份/进度和一项主要学习行动；课程按教材与单元形成可访问的竹林路线。将消费、设置和管理入口分区，建立“学习 / 探索 / 排行 / 小屋”导航。
- 手机优先重排 360/390/430px 页面，处理底部安全区、软键盘、横屏、平板及桌面；采用明确的主次按钮和可点击头像入口，保留触摸尺寸，消除重复的头像大按钮。
- 普通点击、选择、切换和学习反馈增加一致的轻音与短动效，支持音效/朗读独立控制、减少动态效果及录音/播放避让；视觉反馈始终可独立理解。
- 拆分目前共用“我的学习工具”内容的排行和商店页面，保留已有地址、会话恢复、服务端数据、头像并发规则、模拟联赛及奖励行为。

## Capabilities

### New Capabilities

- `child-friendly-presentation`: 森林主题、各角色视觉一致性、控件层级、响应式布局、头像面板与视觉验收门槛。
- `child-learning-navigation`: 儿童首屏学习行动、单元路线、四入口导航及明确的功能归位和恢复路径。
- `learning-interaction-feedback`: 点击与学习音效、动效、偏好隔离、朗读/录音避让和无声音/少动态降级。

### Modified Capabilities

无。`preset-avatars`、`league-avatar-display` 的已归档行为契约继续适用，本变更改变其布局和呈现，不重写头像归属、保存/冲突、稳定影子同学或奖励规则。M1 尚未归档的权限和学习能力继续作为当前实现基础。

## Impact

主要涉及 `apps/web/src/components/{account,learning,avatars}`、`app/{login,change-password,admin,parent,learn}`、`cloud/app/`、样式与设计素材、`lib/{sfx,tts,haptic}` 和云端偏好/导航层。复用现有 API；允许在客户端补充已有接口的只读查询，不规划数据库迁移、奖励修改或新学习算法。旧本地模式需兼容回归，不能直接挂载依赖本地 progress store 的旧导航；iOS/Android WebView 加载相同云端页面可受益，但原生工程重写、安卓默认站点切换、M2 诊断和 M1 录音验收不在本变更内。
