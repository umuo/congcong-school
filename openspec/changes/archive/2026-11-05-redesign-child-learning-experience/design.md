# Design

## Context

动机、用户确认的森林方向和页面范围见 proposal.md。该变更跨导航、布局、音频和账号共享控件，涉及状态恢复、样式隔离及移动端交互，需要设计文件。

已核对的实现：

| 当前基础 | 设计约束 |
| --- | --- |
| `account/account.css` 给账号区所有 button 使用同类填充、尺寸及外观 | 拆分儿童壳、账号壳与题型控件，显式定义按钮层级，避免全局覆盖 |
| `CloudLearningWorkspace` 在课程前渲染完整 `CloudEconomy`；`/profile/` 仍显示学习工作区，排行/商店共用工具集合 | 按页面职责拆分，课程先于消费，保留已有 URL |
| `AccountShell` 与学习首页分别渲染 `AvatarEditor` | 一个紧凑入口，选择器在浮层中打开；不复制有效头像状态或失去 revision 快照 |
| 旧 `BottomNav`、`PathMap`、`MuteToggle` 有导航、动效和音效，但依赖本地 progress | 可复用样式和纯组件，云端适配仍从 LearningClient/服务端读取，不能直接导入本地 store |
| 现有 Panda Mascot、16 款 Canvas 头像、10 类装扮主题及配色检查 | 延续角色身份、装扮锚点和头像 ID；新场景与已有装扮、深色主题可共存 |
| `sfx.ts` 有 tap/correct/wrong/complete 等；runner 已触发判分/结算音效；首页普通点击基本未接入 | 统一用户意图反馈，不对组件渲染或后台读取播放声音 |
| 音频偏好当前为内存全局值；`tts.ts` 复用 sfx 的 isMuted | 独立音效和朗读设置需兼容迁移，不能只改 UI 开关导致另一通道被误静音 |
| 活跃会话 GET 已允许按教材、不指定 kind 查询；客户端封装当前要求 kind | 可扩展只读客户端查询，不需新后端；仍由服务端校验学生和会话 |
| 云端静态构建过滤答案；M1 学习操作保留原幂等键 | 设计素材、文案和 mock 不得把题库答案带进 cloud 产物；展示变更不清学习队列 |

## Goals / Non-Goals

**Goals:** 首屏可发现的学习任务；跨页面一致的森林视觉；手机、平板、桌面均合适的密度；声音与动效可控；保持云端权限、学习记录和既有主题权益。

**Non-Goals:** 新教学内容、强制线性解锁、真实用户排行、奖励改价、背景音乐系统、原生壳重写、离线账号体系或 UI 改版顺带实施 M2。家长/管理员仍以清晰管理流程为主，不把敏感操作变成游戏。

## Decisions

### 1. 视觉选择先于代码

实施阶段先以真实 390px 首页和现有熊猫/头像为参照，生成同一“熊猫森林探险”主题的三份手机首页稿（路线突出、今日任务突出、营地场景突出），展示给用户选择。三稿均满足首屏学习入口和同一信息架构，不重新询问已确定主题。

用户选择前只做截图、素材和设计稿，不改应用代码、测试实现或启动实现型原型。选中后再补齐答题页、头像底部面板、排行榜以及平板/桌面适配的参考，并冻结一份可追溯的视觉基线。任务保留该确认关口，未获选择不得把任意一稿当作默认通过。

当前提案仅规定方向和行为，像素、插画细节及轻音音色在这一步定稿。与直接改 CSS 相比，先做视觉稿能验证整体密度，避免边写边换风格。

任务 1.1 的视觉稿已交付到 [外置盘设计输出](../../../deploy-output/child-ui-redesign/README.md)。三张图片在本次聊天中的实际展示顺序对应 1、2、3；原图、参照截图、提示词和哈希记录均在该目录。用户已选择第 2 稿 `02-home-mission.png` 作为本次视觉基线；第 1、3 稿保留为未来多主题设计参考。本次只落地第 2 稿，不顺带实现新增多主题切换。

### 2. 设计语言与控件层级

默认场景采用奶油白底、嫩绿植物、天蓝留白和深色正文，竹叶、云朵、路径与熊猫伙伴形成完整场景。插画位于欢迎区、路线边缘和完成状态；题干/答案区使用安静、清楚的表面。背景不承载唯一的语义信息，装饰不可拦截触摸。

建立颜色、字体、间距、圆角、阴影、按钮和焦点 token。主按钮用于本区唯一关键行动；次要操作使用描边/轻表面；导航和设置采用图标加短标签。按钮视觉体量按用途收敛，触摸区域至少 44×44 CSS px，不把所有操作拉成整行大色块。新元素需要清晰焦点、正文和按钮文字对比度检查，状态不只靠颜色。

保留现有熊猫主体与装扮叠加能力；森林插画优先利用合适的已有素材，不足时在设计阶段生成或制作真实插画资产。16 款头像仍用原 Canvas 绘制，不能替换成不一致的 emoji/远程图片。森林为默认视觉，已装备的其他主题通过同一结构和适配 token 显示，不能覆盖购买记录、装备选择或暗色模式。

登录页提供轻量森林欢迎场景；家长和管理员共享字体、颜色、按钮层级及状态样式，管理表格/表单保持紧凑可读。可访问名称、密码提示和敏感操作确认继续有效。

### 3. 儿童信息架构

| 区域 | 内容与去向 |
| --- | --- |
| 学习 `/learn/` | 紧凑头像/昵称、简洁进度、熊猫欢迎与主要学习行动；顶部显眼的语文/数学/英语/科学切换、单元路线、挑战/复习入口 |
| 探索 | 使用当前授权教材的 `/stories/[book]/` 展示故事、听读/跟读入口，连接已有 reading/stories 地址；未配置教材显示明确提示 |
| 排行 `/league/` | 只呈现模拟联赛、头像、排名和原有说明，结算按钮与只读刷新分开 |
| 小屋 `/profile/` | 本人头像、已拥有装扮、声音/动态设置及需要的账号操作；通向 `/shop/` 的明确入口 |

四入口为设计默认命名。所有已存在的书本、课程、挑战、阅读、数感和复习直达 URL 继续可用；不把排行、商店再重定向到同一个通用工具面板。探索复用已有路径与当前教材，不增加独立后端模块。

首页在 390×844 可视范围内完整显示一个可操作的主要学习行动。正常状态优先当前教材可恢复的活跃会话，其次目录中第一项尚未完成课程；全部完成则给明确复习行动。会话信息来自现有授权查询，点击恢复既有 ID，不因浏览首页创建会话。教材使用人能理解的名称；目录信息暂缺时使用明确的学科/年级文案，不显示实现 ID。

课程按单元和教材顺序形成竹林路线，展示已完成/可学习/当前项，同时有可访问的语义顺序或列表呈现。地图只表达既有学习状态，不发明服务器尚未限制的锁关；跳级、错题及数感等原入口仍可找到。首屏规则在缺教材、断网和未同步场景以对应提示/恢复行动替代，不伪造可继续状态。

### 4. 页面、浮层与响应式

在 360/390/430px 设计并验证密度；底部导航处理 safe-area，答题键盘打开时让出可见题面和提交区，学习过程中采用沉浸布局，减少与答题无关的导航。200% 文本放大、长昵称、长教材标题和横屏应自然重排。

平板/桌面使用主学习区和任务侧栏，限制题干行宽，导航适配大屏，不把手机控件无限横向拉伸。

头像展示为可点的紧凑身份控件，单页同一主体仅一个修改入口；孩子模式只呈现孩子。手机选择器使用限定高度的底部面板，桌面使用对应对话框；预览、16 项选择和保存/取消各有明确位置，内容可滚动，操作区不遮挡选项。打开时保存的 revision 不随后台读取更新；冲突后读最新、失败可重试、取消不写、关闭返回触发器焦点。支持键盘、Escape 和必要焦点管理，不让背景控件与面板同时操作。

答题、故事/听读、结果页采用统一卡片和反馈语言，但题型特有键盘、连线、证据点选、课程恢复及同步提示保持可用。错误/网络状态使用儿童可理解的提示及明确行动，不靠隐藏数据状态换取视觉简洁。

### 5. 音效、朗读与动态

沿用现有 Web Audio 音源，为点击/选择/导航、判分、完成定义事件表。每次用户意图最多播放一次对应反馈；选择变化与后台刷新分开，不在渲染、路由恢复、幂等重放或重试返回时重复发声。学习成功音只跟随已确认结果，错误提示轻柔且附有文字。

音效和自动朗读使用独立控制。浏览器首次手势后解锁音频，未交互时不自动尝试持续播放；受阻时保留静默操作，失败不阻断学习。朗读/听读及录音过程中抑制装饰性点击/庆祝音，题目必要语音仍遵循当前阅读流程。音色验收需要能听音的设备，不能用“代码已调用”代替实际听感。

新增偏好仅保存音效、自动朗读、减少动态等非敏感设置，按有效学生/账号的稳定 ID 隔离，不存凭据、答案或奖励；刷新可恢复。无新偏好时默认轻音开启、自动朗读沿用当前默认、动态跟随系统。遇旧静音设置时映射到兼容状态，不能将静音用户自动变为有声。存储不可用时使用内存并清楚反映本页设置。

当前全局 sfx.isMuted 同时被 TTS 和 haptic 使用，实施需明确旧接口适配器及作用域加载/重置，再逐步拆分音效和朗读，不直接改变 local 调用含义。切换身份立即停掉旧声音，加载新范围偏好。手感反馈为可选增强，不依赖所有设备都支持振动。

动效以短按压、选中变化、路线推进和熊猫回应为主；减少动态设置/系统偏好关闭非必要持续动画和位移，以静态强调替代。不会添加常驻背景音乐或全屏闪烁特效。

### 6. 云端状态与性能边界

儿童导航和页面使用 CloudLearningClient/LearningProvider；从旧组件抽取纯展示部分，不能复用其本地 store 读写。保留 AccountGuard 的身份边界，头像专用通知继续独立于清理待同步操作的会话事件。

展示/导航不触发购买、领奖或周结算。存在未同步操作时保持其学生范围与原幂等键，提供可见恢复入口，不将新的导航动作重标到其他学生。只读默认页面可恢复已有会话和进度，不另开空会话。

素材经过尺寸匹配、压缩、延迟加载和静态背景分层处理；首屏关键身份与学习行动不依赖大插画加载完成。云端构建仅导出公开设计素材/目录，不挂载原 local 的答案 JSON；新增视觉稿及测试样例不进入生产资源白名单。设计记录、截图、大文件与缓存放外置盘，生产依赖优先复用已有库。

## Risks / Trade-offs

- [变成另一套堆叠卡片] → 三稿先验手机首屏、主要行动及导航位置，用户选择后建立全站视觉基线。
- [缩小按钮伤害触摸] → 缩小视觉强调而保留 44px 触摸区、焦点和足够间距，做真机操作检查。
- [森林背景干扰学习] → 装饰围绕题面、限制动效，读题区维持清晰表面与对比度。
- [旧导航复活本地权威状态] → 纯展示拆分、禁止云端导入本地 progress；以 LearningClient 回归和答案扫描验证。
- [静音拆分误影响 TTS/跟读] → 兼容映射、明确通道状态与冲突优先级，覆盖拒绝播放和录音生命周期。
- [手机路由/浮层清空草稿] → 按上下文恢复原会话/待同步字节，反复验证打开头像、导航返回及失联恢复。
- [改视觉导致已有装扮失效] → 保留主题/装备 ID 与熊猫叠加锚点，验证现有主题与无权益用户。

## Migration Plan

1. 实施前完成三份手机稿的用户选择与关键页面视觉基线，不修改数据库。当前提案不等同于视觉稿已验收。
2. 实现范围内的共享 token、儿童壳、账号壳及受控页面适配；旧地址兼容，云端与 local 分别构建。
3. 在已授权隔离环境保留当前兼容头像 API 与旧 Web 发布目录，先验证客户端及云端答案扫描，再原子切换新静态 Web/Caddy 挂载。音频偏好存储格式版本化且可向旧设置降级读取。
4. 发现严重布局、音频或同步问题时回滚到仍支持 16 款头像 ID 的兼容 Web/API，保留数据库、记录、权益和设备偏好；不回滚到旧四值头像 API。
5. 记录 360/390/430、平板、桌面、双浏览器的证据；iOS/Android 的安全区、键盘和听感以实际可用设备验证，设备缺失时保留明确待办，不代替 M1 录音实测。

### 用户复核：儿童导航的登录外壳

儿童区在根布局保留同一 AccountGuard/LearningProvider/ChildShell，页内 Guard 继承当前已验证身份且仍检查 destination。常规子页跳转不重新挂载登录检查/学习客户端；工具入口使用站内客户端导航。首次进入、30秒后台轮询、前台恢复、身份变更/过期/再验证仍维持原规则；没有新增持久化账号缓存或跳过后端鉴权。页面退出清理其拥有的媒体，不再依赖卸载整个登录壳。

### 用户复核：切换学科而非教材

学习与探索页面顶部常显四学科栏，滚动时固定在安全区下方。儿童选择学科后读取家长为该学科配置的教材，不提供教材版本下拉框、不写 curriculum 配置。未配置或未启用学科显示“待配置”，保留已授权旧教材深链接；当前选择按学生保存，学习/探索导航沿用。切换中隐藏上一学科课程，丢弃迟到响应，使用真实进度和原活跃会话；浏览与切换不开始课程或发奖励。

### 用户复核：排行榜、小屋和输入流畅性

排行榜去除顶部长说明与手动刷新按钮，打开页面及头像变更时读取榜单，只留简短模拟标识，周奖励仍需显式领取。小屋以“我的装扮 / 任务奖励 / 学习设置”分区，一次展示一组；每日目标用按钮直选，家长操作与退出收进家长账号区域。

题目输入不再以700ms计时逐次写云端 checkpoint 并锁住键盘。草稿在当前标签页 sessionStorage 内按 context、学生、会话、题目版本与服务端 revision 隔离，最多保留24小时；存储受限仍保持输入可用。检查答案携带完整答案与证据，主动返回时先同步脏草稿再退出，失败保留页面和原幂等操作；提示、连线逐对判定、学前步骤和时间回执维持既有明确操作。刷新/导航恢复同一有效上下文的本机草稿；跨设备未提交文字不会实时同步，界面明确说明。

### 用户复核：浮层反馈与已装备状态

成功提示显示为固定于底部导航上方的可访问浮层，3.2秒后自动消失，可手动关闭，不插入正文或推移卡片。同步进行中/尚未完成的操作也用浮层反馈，失败重试保持可达，关闭提示不清除原待提交操作。

装扮按mascot_skin/ui_theme/lesson_backdrop读取各自服务端当前装备字段；已装备显示“已穿上”并禁用，当前请求项显示“穿上中…”，成功后才更新装备。固定按钮宽度并保留触摸尺寸，不能因提示出现、禁用、文案变化而移动卡片。不更改权益、价格或装备规则。

### 用户复核：头像焦点与请求等待

首次打开头像面板先聚焦标题，避免浏览器默认聚焦第一个熊猫与当前选中头像形成两个选中框；真正键盘焦点使用虚线轮廓，与绿色选中/勾号区分，关闭回到触发器。头像已确认更新事件复用服务端返回值，不额外读取自身头像；后台焦点恢复仍重新校验，打开面板的revision保持冻结。保存提示采用浮层，不挤动页头。

性能先采样服务器本机与公网连接，不因感觉慢直接增加后端Redis。仅在有效LearningClient内对公开课程目录缓存30秒、商店目录缓存5分钟，同路径并发合并、最多12项、返回独立副本，身份撤销清空且迟到响应不能回填。鉴权、课程配置、学生进度、头像读取、题目/会话、作答、奖励不进入缓存；未确认写入保留原字节及幂等键。

### 儿童界面继续改进：可视化装扮与可恢复空状态

在用户确认继续儿童界面后，沿用既选森林视觉：衣柜和商店按熊猫装扮、界面主题、答题背景分区，以两列预览卡片呈现。预览使用既有森林角色图、原装扮renderer或主题/背景配置，不新增付费资产、不自动购买或改变权益。卡片按钮在同一布局内尺寸固定，延续正在穿上/已穿上与浮层反馈。
