# Proposal

## Why

聪聪学堂已有完整儿童学习体验和本地多孩子档案，但缺少家庭身份、服务端权限、跨设备同步及可追溯作答记录。家庭长期使用需要在保留现有教材与交互的基础上，建立可信的学生数据基础，为后续诊断与学习计划提供证据。

## What Changes

- 先补齐 M0 运行基线、资源完整性检查和审计报告，验证原有学习路径后再开始 M1 业务改造。
- 增加统一登录入口，由服务端识别管理员、家长、学生身份，分别进入管理后台、家庭首页和学习首页；关闭公开注册页面及后端公开注册接口。
- 部署时初始化一个管理员，初始凭据由配置提供，首次登录必须修改密码；管理员统一创建、停用家长和学生账号、关联家庭及重置密码。
- 普通家长与学生首次登录、密码重置后均无需强制改密；建号账号实时查重，设置密码时前端重复确认。
- 保留可撤销会话、家庭成员模型和家长代入的孩子学习模式；学生可独立登录且只能访问绑定学生的学习数据，家庭管理和敏感操作需家长再次验证。
- 增加学生创建、编辑、归档、切换，以及独立的学科和教材配置历史。
- 保留 Web 儿童组件及静态媒体，增加 FastAPI、PostgreSQL、SQLAlchemy、Alembic 模块化单体后端和统一 API 访问层。
- 增加服务端题目版本、判分、逐次作答与学习事件、幂等结算和多设备读取；覆盖课程、挑战、跳级、错题、故事与阅读等已有学习入口。
- 提供旧本地档案预览导入、数据导出与删除，区分不可追溯的历史摘要和新产生的学习事件。
- **BREAKING**：云端模式不再公开含答案的课程 JSON 或构建页面数据；需要部署 API 与数据库，并清理旧站点答案资源和缓存。原静态本地模式保留为独立构建目标，不与云端模式共用含答案的发布目录。
- 本变更不实现 M2 知识点诊断、M3 个性化计划、M4 Capacitor 替换、M5 AI，也不修改 iOS 云端接入；这些阶段继续沿用原需求范围。

## Capabilities

### New Capabilities

- `family-access`: 管理员初始化、集中建号、三类身份登录、家庭权限、孩子模式和敏感操作验证。
- `student-profiles`: 多孩子档案生命周期、学生账号关联及隔离。
- `student-curriculum`: 配置驱动学科、教材选择与历史。
- `cloud-learning-records`: 服务端出题判分、学习事件、同步及结算。
- `learning-data-portability`: 本地档案迁移、家庭数据导出与删除。

### Modified Capabilities

无。当前主规格目录为空；以上能力是首次登记，不表示原应用没有对应的本地功能。

## Impact

新增 `apps/api/`、API 测试、迁移、统一登录、管理员与家长页面及前端 API 层；调整 `apps/web/src/store/progress.ts`、`lib/learnerProfiles.ts`、课程/复习/阅读/故事入口和数据构建。保留 `packages/core` 为前端业务复用与服务端规则对照基线，保持教材 ID、旧成绩和上游合并路径。部署增加数据库、API、同源代理、管理员初始化和云端资源过滤。三类身份登录和账号管理已完成本阶段实现与验证，学习记录等未完成范围仍以任务清单为准。具体文件、模型、接口、兼容及验证方案见 design.md 和 tasks.md。
