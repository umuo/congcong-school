# 家庭数据导入、导出与删除

家长在 `/parent/` 选择孩子后可预览、确认导入；家庭设置提供全家庭下载。敏感操作要求最近五分钟验证过家长密码。学生和部署管理员不能导出家庭数据。

## 从本地版导入

先在本地版切换到对应档案并导出 `cstf-backup` v1 JSON，每个文件最多 5 MiB。预览明确显示目标孩子、映射数量、未知来源与冲突，再确认导入。预览有效期三十分钟；预览后学生配置 revision 或学习游标变化时返回 409，必须重新预览。同一学生、同一规范化文件哈希只确认一次。

只按原教材和课程稳定 ID 映射，不推断同名课程等价。课程星级、正确率、阅读和旧装扮作为 `legacy_unverified` 历史摘要单独展示；旧错题的版本未知，不假定等于现行版本。不导入 XP、宝石等可消费余额，不生成作答证据、不触发奖励、不覆盖新云端成绩。未知来源保留在报告中。原设备与下载备份均不会删除。

## 家庭导出格式

下载文件使用 `schema: cstf-family-export`、`version: 1`，含导出时间、家庭、所有孩子（含归档档案）、学科与教材选择历史、学习会话、逐次作答、事件、当前进度、奖励与领取记录、已确认历史导入。学生账号关联和家庭成员仅导出 ID、登录名、昵称、角色等明确白名单字段。

文件不含密码哈希、认证 Cookie/令牌、CSRF 或限流记录，不含其他家庭数据。它是可读的数据副本；当前不支持直接把该格式恢复为活动数据库，也不凭该副本重新发奖。请妥善保管含孩子学习记录的下载文件。

## 删除范围与恢复管理

删除单个学生会清理其档案、选书、学习与奖励记录、导入摘要和绑定学生账号，撤销独立登录与家长代入会话；其他孩子保留。家庭所有者可删除整个家庭及其家长、学生账号，部署管理员保留。停用账号只撤销访问，保留数据；归档学生保留历史并禁止学习。页面要求输入显示名称，API 另要求精确目标 UUID 和幂等键；单个学生删除可用原键重放，不能改目标复用原键。

`CSF_BACKUP_RETENTION_DAYS` 为 0 时，本应用不自动生成外部备份；若运营者另建备份，必须配置实际保留期（最多 365 天）并按期清除。删除前把仅含目标 UUID、类型、申请时间和到期时间的删除意图写入 `CSF_DELETION_JOURNAL`，权限 0600、文件锁和 fsync。该文件必须放在私有持久卷，独立于数据库备份，严禁放入 Web public。

恢复旧备份时保持服务关闭，先应用迁移，再在 API 目录执行：

```sh
uv run python -m app.portability.replay
```

确认所有过期备份已销毁后，离线执行 `uv run python -m app.portability.replay --purge-expired` 清理超期最小清单。重放失败必须保持访问关闭。用户自己下载、截图和其他设备副本需自行清理。
