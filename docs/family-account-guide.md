# 家庭账号与登录使用说明

当前已接入统一登录、管理员首次改密、管理员建号、家庭档案与教材配置。云端课程、服务端判分和学习记录仍在开发；学生学习首页明确显示此状态，不把原本地成绩当作已同步的云端记录。

## 本地预览

需要 Node.js 20 以上、Python 3.12 和可访问的 PostgreSQL。依赖与数据库隧道准备见 [API 说明](../apps/api/README.md)。不要把实际数据库或管理员密码写入受版本控制文件。

首次设置 `apps/api/.env` 中的 `CSF_BOOTSTRAP_ADMIN_LOGIN`、`CSF_BOOTSTRAP_ADMIN_PASSWORD`，密码 12–128 字符；没有内置通用密码。在项目根目录打开第一个终端：

```sh
cd apps/api
uv sync --frozen
uv run alembic upgrade head
uv run python -m app.curriculum.import_catalog
uv run python -m app.auth.bootstrap
CSF_COOKIE_SECURE=false CSF_PUBLIC_ORIGIN=http://localhost:3010 \
  uv run uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8000
```

另一个终端从项目根目录启动前端。已有完整生成数据时使用隔离入口启动，无需重新下载资源：

```sh
CSF_DEV_API_URL=http://127.0.0.1:8000 npm run dev -- --hostname 127.0.0.1 --port 3010
```

打开 `http://localhost:3010/`。默认使用 cloud 账号模式，首页、原课程/复习/商店等页面入口均先校验会话：未登录转 `/login/`，已登录按服务端身份进入管理、家庭、学习或首次改密页；服务不可用时显示重试，不能退回免登录本地页面。开发代理将同源 `/api/` 转到 API，避免在浏览器设置跨域地址。浏览器地址必须与 `CSF_PUBLIC_ORIGIN` 完全一致；改端口或使用 `127.0.0.1` 时也要同步修改 Origin。`CSF_DEV_API_URL` 仅在 Next 开发服务器生效，默认 `http://127.0.0.1:8000`，不填使用默认值。

仅在明确需要原离线学习流程时，于启动或构建前设置 `NEXT_PUBLIC_APP_MODE=local`；合法值为 local/cloud，空值默认 cloud，修改后需重启或重新构建。local 模式免登录且使用原本地档案，不能作为云端登录是否生效的验收入口。`apps/web/out` 中旧的静态导出同样不代表当前账号版本。当前已新增 local/cloud 独立页面树与产物，启动、构建及打包必须使用 [隔离构建说明](local-cloud-builds.md) 中的命令；不可发布旧 `out` 或叠加原公开资源。

正式部署需 HTTPS 同源代理并保持 `CSF_COOKIE_SECURE=true`；静态导出不会内置开发代理。原本地学习模式仍保留，云端资源隔离已完成构建验证；完整 HTTPS 发布与旧缓存清理另按 OpenSpec 部署任务验收。

## 管理员开通账号

1. 使用初始化配置中的账号、初始密码登录，按提示设置新密码后进入管理后台。
2. 在“家长账号”填写账号、昵称和初始密码，创建新家庭或关联已有家庭。新家庭家长为 owner；关联已有家庭时保留原 owner，新家长为 guardian。
3. 在“学生账号”选择所属家庭，可新建学生档案，也可关联家长已创建的档案。关联已有档案保留原教材和学习历史，每个档案至多一个登录账号。
4. 将账号密码交给本人，普通家长和学生可直接登录，无需首次改密；页面和列表不回显密码。

账号名为 3–320 个字母、数字或 `._@+-`，不能包含空格，大小写按同一账号处理。学生无需邮箱。管理员可停用普通账号或重置密码：停用后无法登录，重置后可直接使用新密码登录，无需强制改密，所有旧会话撤销，学习记录保留。当前后台没有在线新增管理员、代登录或家庭学习明细入口。

## 家长管理两个孩子

家长登录后进入家庭首页，在“添加孩子档案”中填写昵称、头像、年级、学期及每日目标；出生年月、地区、学校、备注可选。创建档案不自动开通独立账号，需要时由管理员关联。

选择孩子后可编辑档案、打开教材配置或进入孩子模式。各学科独立启停、手动选书及设置当前单元；无可信地区推荐时显示说明，不强制指定出版社。教材保留原 ID，未知出版年份与 ISBN 显示“未知”。默认显示孩子当前年级，也可勾选全部年级；原教材、停用科目和换书记录保留在“选书历史”。

归档需确认，归档后该孩子不能继续学习或独立登录；勾选“显示已归档档案”仍可查看资料。归档与停用账号都不是删除历史。资料发生并发修改会提示刷新，不能静默覆盖其他页面的修改。

## 学生与共享设备

学生使用管理员开通的账号直接登录进入自己的学习首页；不能查看兄弟姐妹、家长备注或家庭管理。需要家长操作时退出，再使用家长账号登录。

家长也可从档案代入孩子模式，共享该登录 Cookie 的标签页同时降权，其他设备会话独立。返回家长端需原家长密码，学生本人密码不能取得家长权限。管理页面超过默认五分钟验证窗口会要求重新验证，不自动重放未完成写操作；重新进入后按最新资料编辑。

退出、切换身份、停用或会话撤销后清除页面敏感展示并取消旧读取，旧账号的响应不能显示为新账号。当前移动验收使用 390px 浏览器模拟，不能替代实体手机或 Android WebView 的验证。
