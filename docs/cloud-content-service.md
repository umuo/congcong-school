# 云端内容与题目版本

内容导入复用原生成题库，不改写教材 ID、课时 ID、原数字题号或知识点标签。API 内容目录与学习作答分开；目录不会返回答案、解析或解释音频。云端发布目录的隔离与学习会话仍须分别通过对应 OpenSpec 任务验收，不能只凭本接口认定整个站点已经保护答案。

## 准备与导入

先按原项目流程准备完整的 `apps/web/public/data/`，在仓库根目录生成数感复习的私有输入：

```sh
node --import tsx scripts/cloud/export-number-review.mts
```

然后在 `apps/api/` 中执行：

```sh
uv run alembic upgrade head
uv run python -m app.curriculum.import_catalog
uv run python -m app.content.import_content
```

`CSF_CONTENT_ROOT` 指向内容仓库根目录，默认定位当前仓库。数感导出写入被 Git 忽略的 `apps/api/private-content/number-review.json`，记录生成源码的 SHA-256；源码变化后必须重新导出。它保留原实现的三项技能、奇偶日期两套题，不另造随机题库。

导入以全部教材为一次完整发布，使用事务锁串行执行；失败不会发布半套内容。重复导入复用已有身份和版本，修订后只追加新版本并切换当前指针。新清单移除的课时停止作为当前入口，旧版本继续保留供历史记录引用。不要用只含一本书的目录执行全量发布。

缺少所需文件、课时身份重复、同课重复题号、教材归属错误或数感导出过期会拒绝导入。目录内未被 outline 引用的课时文件单独列在 `unmapped_files`，不会猜测其所属课程或知识点。内容文件路径必须位于配置根目录内。

## 身份与不可变版本

题目身份由内容类型、教材 ID、精确来源 ID、原数字题号共同生成。不同课时的题号 `1`、不同版次的同名课程、课程和故事中的同名知识点均保持不同身份。跳级题目引用前置普通课的原题目身份，不复制成新题；数感复习的同一技能题目在奇偶日期使用同一身份的不同版本。

题目版本哈希覆盖完整题目与 `grading_rule_version`；内容版本覆盖公开元数据及有序题目版本引用。数据库触发器禁止更新、删除版本或改写身份，只允许切换发布指针和停用入口。历史作答应固定引用题目版本，不能改为读取当前答案。

原题库中有 26 处题目字段、1 处公开元数据含转义 NUL 字符。题目和元数据使用 PostgreSQL JSON 无损保存；引用与来源仍使用 JSONB。禁止静默删除字符或猜测缺失公式，原文件保持原样。这解决存储兼容性，不代表原内容质量问题已修复。

## 读取接口

所有接口需要有效登录，前缀为 `/api/v1/content`：

| GET 路径 | 返回 |
| --- | --- |
| `/books/{book_id}` | 当前内容的类型、来源、版本、标题、单元和题目数量 |
| `/books/{book_id}/{kind}/{source_id}` | 公开元数据及题目版本引用；可用 `version` 指定已有内容版本 |
| `/books/{book_id}/jump-pool?target_unit=2` | 目标单元之前的普通课版本引用，保留原课时归属与顺序 |
| `/question-mapping?kind=lesson&book_id=...&source_id=...&question_id=1` | 精确来源对应的稳定题目身份 |

`kind` 包括 `lesson`、`challenge`、`story`、`number_review`、`reading`。跳级从普通课池构造，听读可以没有题目。不存在、停用入口、未知版本与未知映射分别返回稳定的 404 错误，不按标题或知识点名称自动匹配。此处没有公开的私有题目读取端点。

`public_question` 是后续授权学习会话使用的白名单 DTO：仅含题干、题型、必要选项、展示字段与题干/选项音频，排除答案、解析、解析音频和故事证据答案。目录接口本身只返回题目引用。

## 验证

`apps/api/tests/test_content.py` 覆盖同题号跨课/跨教材/跨类型、数感变体、重复导入、修订后旧版本保留、未知来源、停用入口、无答案 DTO、登录限制和直接 SQL 改写拒绝；包含转义 NUL 的真实数据库往返。迁移与模型一致性检查位于 `test_foundation.py`，只操作自动创建并清理的临时数据库。
