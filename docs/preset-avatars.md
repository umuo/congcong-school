# 内置头像

目录的唯一来源为 `apps/api/app/avatars/catalog.json`，首期 16 款。ID 为不超过 32 位的小写稳定标识；不可重命名或复用旧 ID。新增时增加目录版本，在 Canvas 绘制器注册相同 ID，然后运行 `node scripts/cloud/export-avatar-catalog.mjs`；`--check` 用于验证已导出文件与 API 一致。构建自动导出，不读取题库或个人资料。

`GET /api/v1/avatar-presets` 返回版本、默认 ID、具名目录，要求登录和完成首次改密。`GET /api/v1/me/avatar` 返回 `{scope_kind,subject_id,avatar_id,revision,catalog_version}`，不支持传入目标身份。账号模式使用 User；两类孩子模式使用同一个 Student。学生 User 的头像及版本为空。

`PUT /api/v1/me/avatar` 只接受 `{avatar_id}`，同时要求 `If-Match` 和当前 `X-CSF-Learning-Context`，并遵循 Origin、CSRF、账号有效和首次改密检查。家长/管理员修改本人头像要求最近验证；孩子不需要提供家长密码。401 表示会话失效；403 表示身份、来源、改密或最近验证限制；409 表示版本、上下文冲突或孩子归档；422 表示非法值、未知字段或无效版本；428 表示缺少版本或上下文。头像不得为 URL、Data URL、空值或自定义脚本。

Student 创建/更新共用目录白名单，未指定头像的新孩子使用 panda。档案整体 revision 同时保护头像，家长旧表单不能覆盖孩子的新选择。家庭导出增加成员头像；学生账号导出的头像从 Student 派生。导出不添加认证字段，头像随原账号/档案删除，不需要独立文件清理。旧学习记录导入不更新头像。

迁移 0011 在 0010 后增加 User 头像和头像版本，现有家长和管理员设 panda/1，学生账号保持空值，保留所有孩子原值。运行时权限脚本对业务表使用表级 SELECT/INSERT/UPDATE/DELETE，新列继承该授权；部署仍需验证实际运行角色。

生产回滚必须保留能读取新增 ID 的 API；不能回退到四值校验的旧 API，不能把新值全部重置为 panda。降级/再升级仅在临时测试数据库执行。隔离部署先备份，再迁移和发布兼容 API，最后切换 Web。原 cstf_dev 不参与迁移。

账号页顶部的“我的头像 · 修改头像”适用于三种身份；管理员管理页、家长家庭设置及孩子学习首页也有直接入口。点击选项可预览，点击“保存头像”才提交；取消不保存。冲突后点击“读取最新头像”并重新选择，不自动覆盖另一设备。网络中断后可先读取最新头像，确认丢失响应的保存是否已成功。

家长在“编辑档案”中为孩子选择头像，随“保存档案”一起生效；添加孩子同样可选，默认熊猫。归档档案头像只读。代入孩子时修改的是孩子头像，恢复家长模式后仍显示家长本人的头像。学生只能修改当前头像，不能访问其他家庭资料。可用 Tab 与方向键选择内置选项，触摸目标大于 44px。

排行榜仍为模拟联赛：影子同学身份在排序前确定，使用独立且固定的 v1 头像候选池，不影响原姓名、XP 和周奖励。打开榜单或头像更新后的展示刷新仅执行 GET；“刷新联赛并结算已结束的一周”保留原显式结算行为。

头像更新采用独立 `csf-avatar-updated` 通知，仅刷新展示，不调用 `announceSessionChange`。请求绑定 context_id 与主体，卸载中止；已打开的选择器保留打开时 revision，即使焦点刷新已读到新版本，也必须先解决冲突。保存响应丢失后可读取最新状态，不自动创建一次覆盖更新。

验证命令：`npm run check:avatars` 检查目录、所有绘制器、SSR/无上下文默认外观、DPR 1/2/3、显式表单字段、选择/取消/保存/冲突、上下文与迟到响应、网络丢失以及原待同步字节和幂等键保留。`apps/api/.venv/bin/pytest -q` 在设置 CSF_TEST_ADMIN_DATABASE_URL 后仅创建随机 cstf_test_ 库；禁止把生产库直接当作测试库清空。

## 森林界面的入口

当前身份只在顶部头像处提供一个修改入口；家长管理孩子档案的独立表单仍用于编辑该孩子。手机打开限定高度的底部面板，桌面打开居中对话框，原 16 款 Canvas 头像不变。点选只预览，保存才写入；取消或 Escape 不保存并把焦点还给头像入口。打开期间保留打开时版本，遇到冲突后使用“读取最新头像”关闭并重新读取，再重新编辑。面板不会清除学习待同步操作；网络失败先恢复连接，仍可取消返回。

头像选择面板首次打开聚焦标题，绿色勾选为唯一选择，键盘焦点用虚线区分，取消后返回触发按钮。已确认保存直接采用API响应，不再为自身更新事件重复读取；前台恢复仍读取最新头像，面板打开时的revision不随后台变化。
