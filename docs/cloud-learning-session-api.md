# 云端学习会话契约

学习操作只允许独立学生或家长代入的孩子模式，二者解析到同一个学生范围。管理员没有家庭学习权限；家长需先代入学生。每个请求重新检查启用状态、学生绑定与归档状态，不能通过携带其他学生 ID 取得数据。

本接口负责固定题目版本、判分、逐次作答及可恢复检查点。服务端奖励、完成结算、红心与成长事件已接入，见 [奖励账本](cloud-learning-rewards.md) 和 [学习事件](cloud-learning-events.md)；前端课程尚未切换到这些接口，不能认定整条云端学习流程已完成。

## 请求约定

前缀为 `/api/v1`，认证继续使用 HttpOnly Cookie。写请求需精确 Origin、`X-CSF-CSRF`，以及 UUID 格式的 `Idempotency-Key`。请求体不接受额外字段，不能声明正确率、经验、奖励或替换学生身份。全部响应带 `Cache-Control: no-store`。

幂等范围是学生、操作类型（含会话）、操作标识。相同标识与完全相同请求体返回最初响应，不再追加作答或事件；同标识不同请求体返回 409 `IDEMPOTENCY_CONFLICT`。重试必须保留 `client_at` 等原字段，不重新生成操作标识。

| 接口 | 请求与行为 |
| --- | --- |
| POST `/students/{id}/learning-sessions` | `kind`、来源字段、带时区的 `client_at`；服务端固定当前内容与题目版本 |
| GET `/learning-sessions/{id}` | 当前权威题目、草稿、反馈、队列、会话 revision 和学生变化游标 |
| POST `/learning-sessions/{id}/attempts` | `revision`、`question_uid`、`question_version`、`answer`、`client_at`；可附申报用时、提示级别与故事证据选择 |
| POST `/learning-sessions/{id}/advance` | `revision`、`client_at`；确认当前反馈并进入下一题 |
| PUT `/learning-sessions/{id}/checkpoint` | `revision`、`client_at`，可附草稿 `answer`、`intro_page`、`visual_draft`；不能提交正确率或改写队列 |
| GET `/students/{id}/changes?after=0&limit=100` | 该学生内递增事件游标，返回 `next_cursor`，分页最多 500 条 |

普通课程、挑战和故事需 `book_id` 与精确 `source_id`；跳级需 `book_id`、`target_unit`；数感复习只需 `number_skill`；复习可按 `book_id` 筛选。其余来源字段混用会拒绝。普通学习内容必须属于家长当前已启用、已选择的教材，复习可继续历史教材的错题。数感日期变体由服务端按家庭时区选择，跳级种子由服务端产生并固定抽样，不接受客户端自选题目列表。

## 阶段与恢复

服务端一次只下发当前无答案题目。作答成功进入反馈阶段，才返回该题正确答案、解析、解析音频引用和判分规则版本。反馈可以跨设备恢复；在确认反馈前重复提交新作答会被拒绝。确认后，普通课程、挑战、数感和复习的错误题回到队尾；故事和跳级保持一次作答的原语义。所有首答及回炉作答分别保存，首答错误后再答对不会提高首答正确数。

每次成功修改都增加会话 revision。另一设备使用旧 revision 会收到 409 `LEARNING_REVISION_CONFLICT`，应重新读取，不能覆盖已确认进度。幂等重试在版本检查前返回原响应，因此响应丢失后仍能使用原键恢复。草稿只是界面检查点，不产生作答、正确率或奖励。

题库修订不会改变现有会话的题目版本。私有题目不可变，逐次作答关联确切题目与判分规则；不存在的规则版本明确拒绝，不按当前规则重新解释历史成绩。

## 记录与游标

作答记录保存原答案、结果、首答标记、题目与规则版本、客户端声明时间、数据库接收时间及申报用时。难度、原知识标签与来源通过不可变题目版本追溯。数据库禁止更新作答、事件和幂等回执；学生删除时仍允许按范围级联清理。

学生行锁串行化学习写入及归档，作答、检查点、事件游标与幂等回执在同一事务提交。学习游标与档案配置 revision 分开；阅读一个学生的游标不能绕过学生授权。服务端接收时间使用数据库 `clock_timestamp()`，不使用事务开始时间冒充锁等待后的接收时间。申报用时与提示、证据选择来自客户端，不能证明实际专注度。

复习候选按追加事件重建，课程首答错误保留在错题范围内，后续课程回炉答对不直接抹去错题。到期复习首答按原 SRS 盒子与日期间隔推进；复答不再次推进。完整复习奖励、回心补练及持久投影在相应任务中继续接入。

完整 OpenAPI 可从运行中的 `/openapi.json` 读取。请求模型、公开题目与作答反馈在 `apps/api/app/learning/schemas.py`；前端类型在 `apps/web/src/lib/api/learning-contract.ts`。公开题目类型没有答案或解析字段，反馈类型只用于已提交题目。

## 前端上下文契约准备

账号响应新增非凭据 `context_id`，同一登录与模式保持稳定；重新登录、改密、重新验证或切换学习身份后变化。它不公开原会话令牌、摘要或家长身份，不能用于认证。学习请求可附 `X-CSF-Learning-Context`：与当前真实 Cookie 会话不一致时返回 409 `LEARNING_CONTEXT_CHANGED`，避免旧标签页或待提交请求在切换账号后继续执行。该头只缩小范围，不授予任何权限。

这仅准备了任务 5.4 的契约，前端 LearningClient、取消旧响应、投影缓存和待提交队列尚未实现。不要把 `context_id` 当作已完成前端上下文隔离。
