## 组件与反馈

装饰图片 pointer-events:none；熊猫仍复用现有 Mascot 及装扮叠加，头像仍用原 Canvas。课程插画仅作情境图，不承担题面、教材封面或答案含义。导航使用现有图标库的具名图标；不新增长期背景音乐。

按压最多 120ms；卡片与选择变化最多 180ms；不排队播放动画。系统或本设备减少动态时停用非必要位移和持续动画。点击仅由用户事件触发一次，朗读/听读/录音时避让；判分和庆祝依服务端确认。界面偏好仅保存有效主体的非敏感设置。

## 真实数据边界

设计稿中的“小禾”、XP、宝石、示例课程和排行均为 mock，不进入生产业务数据。应用从当前 LearningClient 读取授权课程、进度、会话和联赛，不导入本地 progress store。浏览不开始会话、不领奖、不购买、不结算；所有写入沿用原权限、revision 与幂等键。

设计稿、参考截图及提示词不得进入 cloud public 白名单。生产仅发布明确列出的森林插画和原有公开资源。M1 实体录音验收继续保留，不因本次视觉/生命周期回归而标记通过。

## 实现中的槽位与按钮隔离

`forest.css` 负责账号壳与儿童壳。`forest-question` 内保留原题型样式，壳按钮规则通过 `:not(.forest-question *)` 排除它；不能给键盘、连线与选项统一涂成主按钮。现有自带 tap 的题型根节点标记 `data-sound-handled`，父壳单次点击代理跳过这些节点，键盘交互继续走原题型事件。头像触发器只在账号壳渲染一次。

`nextActivity` 只选择行为，不发写请求。按教材读活跃会话（未指定 kind），保留服务端返回顺序；命中后恢复同一 ID。未命中才选第一未完成 lesson；否则进入已有 review。网络错误和未加载完时不推测下一行动，待同步时提供原键重试。

教材名称表仅含公开索引中的书名，不含题干或答案。当前教材选择按学生在内存隔离，导航带公开 book 参数；换身份清理，刷新重新由授权教材列表校验参数。深链接不能通过公开书名表取得未授权内容。

`CloudEconomy` 通过 panel 分开页面：league 只读获取联赛、独立显式周结算；shop 显示可购装扮；cottage 显示已有装扮、任务、日目标、补给和设备设置。读取页面不调用 economy 写入。

音效由有效点击冒泡事件触发一次，后台读取无声；已有题型自己的事件不重复处理。朗读/录音各持有独立声音避让 token；停止/结束/卸载释放，重叠时必须全部释放后才能恢复装饰音。效果失败不阻止业务。声音偏好键为 `csf-preferences-v1:<student|user>:<id>`，只含 muted/autoNarrate/reducedMotion，不含 context token、答案或凭据；受限存储回退到本页内存。旧全局 isMuted 仍保留 local 含义，新 effectsMuted 不静音 TTS；旧静音用户初始兼容关闭自动朗读。

## 首屏路线与资源补充

首页先显示围绕当前课程的三条预览（上一项/当前项/下一项），全教材单元、课程与挑战保留在“全部课程与单元”展开区；不新增锁关。展开区保持教材排序和语义列表，复习/数感/跳级仍在教材工具区。首屏书名拆出版本标签，完整名称保留在教材选择中。

原首批资源为五个 WebP：背景 96,288 bytes；主情境图 210,666 bytes；透明书本 11,556 bytes；鸭子路线缩略图 9,216 bytes；苹果路线缩略图 9,636 bytes。总计约 330 KiB。背景不阻塞渲染；主卡和书本有明确尺寸；路线缩略图 lazy；所有插画 alt 为空、pointer-events:none，真实名称和操作来自 HTML。PNG 大图、视觉稿及提示词仅保留在 deploy-output，不进入发布白名单。

探索中的故事按原始教材目录顺序排列；修订教材的起始/综合活动保持目录位置，不简单按数字排序。阅读材料进入后，“返回探索”回到当前教材的材料列表；课程、挑战、复习仍返回学习页。切换只读页面不会创建学习会话。已完成课程的活跃会话标为“正在温习”，尚未开始的推荐课程标为“下一站”，避免把推荐展示成已开始。

## 声音事件与设备边界

| 意图/状态 | 声音来源 | 去重与避让 |
| --- | --- | --- |
| 普通按钮、导航、设置点击 | 账号壳 clickFeedback → tap | 同一个原生 Event 仅一次；禁用/隐藏/自带反馈区跳过 |
| 题型选择、键盘输入 | 原题型 tap | data-sound-handled 防止父壳重复播放；键盘与触摸走同一逻辑 |
| 头像选择变化 | AvatarChoices onChange → tap | 选择器独立处理，父壳跳过；重复点已选项不触发变更 |
| 答对/答错 | 已确认 attempts 响应 | 不在渲染、GET 或草稿恢复播放 |
| 学习完成 | 已确认 settlement 响应 | 原键重试分支恢复结果而不再次庆祝；刷新结果页无新声音 |
| 朗读、听读、录音 | 原媒体/录音生命周期 | 重叠 owner token 全部释放后才恢复装饰音；身份切换停止旧声音 |
| 设备不支持/播放被拒绝 | 静默降级 | 声音异常不阻断操作，不自动标记阅读完成 |

iOS WKWebView/Android WebView 仍受首次手势、前后台、媒体播放与系统麦克风权限限制。独立的“音效”开关不关闭必要的手动听读；“自动朗读”只控制自动叙述。停止、离开、权限失败和录音取消不算阅读完成。当前 Mac 未发现音频设备，音色听感和实体录音没有验收；浏览器实测播放停止与录音不可用时，完成按钮保持禁用。此限制独立于 M1 已保留的实体录音待办。

暗色装备沿用现有 `theme-dark` 表面映射，并保留原 `night` 标识；主题变量由服务端装备 ID 对应的既有目录提供。LearningProvider 集成回归逐个核对全部 10 主题的实际变量与暗色类，避免只通过颜色算法测试却漏掉页面样式钩子。头像对话框显式声明 role/aria-modal，确保原题型的全局快捷键守卫不会接管面板按键。

## 用户复核后的修订（2026-11-03）

用户指出长页面背景消失、儿童端步骤复杂、开始学习无法使用，原首屏结论重新打开。森林场景改为无点击拦截的 fixed 伪元素，覆盖整个视口，页面内容滚动不带走场景；不依赖移动端兼容性较差的 background-attachment:fixed。默认主操作改为 #517c2c（白字对比度约4.92:1），首屏使用独立身份/积分/音效控件及更接近参考的标题比例。原版/学士帽熊猫使用选定绘本方向的透明栅格素材，其他已拥有装扮保留原渲染；素材失败回退到现有熊猫，不影响学习。

正常首页仅提供推荐任务、三条预览、四个导航，完整课程和“换教材与更多练习”默认折叠。复习、回心、跳级、数感仍在同一授权范围内可访问，不删除功能或新增锁关。小屋补给和装扮默认折叠，避免消费按钮群压过学习。

点击明确课程动作时，查询同源活跃会话并恢复原ID；不存在才用原学习接口创建，单次意图由入口 gate 防重复。浏览页面仍全部只读；直达课程地址保留明确开始按钮。学前核心讲解集中为一张卡，其他方法/错误提示仍可展开并播放；一次“开始练习”进入原题序。题型和判分不改写。

pending 继续保存原字节/范围/幂等键；新增仅内存 sending 投影区分正在发送与已失败待重试。正常发送显示“正在保存进度”，结束后自动消失，只有失败才显示“重新保存”。用时事件不改变题目版本，不阻止进入课程；其失败仍有重试入口。取消手动“保存进度”重复按钮，沿用原自动草稿与服务端提交。课程内容未返回时维持准备状态；读取失败提供重读，避免先闪出题目再跳回讲解。

导航/刷新可能在最终用时回执提交前卸载页面；同一身份恢复时，仅补发这些原有用时回执（原范围、字节和幂等键），不重新创建记录，不自动重放开始、答案或奖励。服务端确认后清除原队列，失败保留可见入口。此恢复不代表页面浏览开始新会话或产生奖励。

修复后正式白名单共七张 WebP，总407582字节（约398KiB），新增两张熊猫插画的尺寸、SHA与来源见 production-file-manifest.json / production-assets.json。小屋的导出、历史摘要和账号恢复统一置于默认折叠的“家长小帮手”；周奖励只在用户展开后显式领取，联赛只读加载不触发结算。

## 持续保留的儿童登录外壳

同一文档内的学习/探索/排行/小屋及课程子路径由云端根布局中的 CloudChildBoundary 共用 AccountGuard、LearningProvider 和 ChildShell。页面内旧 Guard 消费外层已经验证的身份，不再重复挂账号壳或创建学习客户端。普通切页保留原待保存操作；站内工具入口改用 Next Link，避免整页重载。首次打开/硬刷新仍校验，30秒轮询、回到前台、跨标签身份变动及重新验证仍保留；过期和身份变动立即卸载旧内容并撤销旧客户端，不增加浏览器存储的登录缓存或凭据。

页面对自己所需 destination 仍作匹配，不能通过继承孩子身份渲染管理页面。登录/管理/改密独立 Guard 与离线目标行为保留。媒体在页面卸载时由拥有者清理，学习会话退出也停止旧TTS，不依赖整个登录壳卸载。

## 排行、小屋与输入复核（r22）

排行榜去掉介绍长段落和刷新按钮，保留短模拟标识；页面打开和头像更新自动读取。小屋为“我的装扮 / 任务奖励 / 学习设置”三个直接切换的分区，默认只显示装扮；每日目标为44px按钮，家长与账号默认折叠，退出不再占页头。任务和成就使用已有core中文名称，不展示内部编号，已拥有装扮不重复标价。

## 操作反馈与装备按钮（r25）

FloatingNotice统一以fixed浮层显示，不占正文高度，成功反馈3.2秒自动收起，可关闭；进行中和失败恢复状态不清待提交操作。小屋/商店的重试按钮归入同一浮层，学习同步提示同样浮动。登录验证与题目判分等必要正文反馈保持其原用途。

衣柜按服务端equippedMascotSkin/equippedTheme/equippedBackdrop独立显示当前装备，不把已拥有误当已装备；当前请求项显示穿上中，成功后才标已穿上并禁用。所有装备按钮固定116px宽，文案与disabled状态不改变卡片尺寸。默认装备值兼容旧投影，未知ID不伪造装备。

## 头像焦点与读取等待（r26）

头像弹窗打开聚焦标题，首次不再给首个熊猫加第二个蓝框；绿色+勾号表示唯一选中项，键盘焦点用虚线区别。关闭仍回到触发器，打开时revision继续冻结。保存确认直接采用服务端返回值，头像更新事件不再触发一次多余自身读取；窗口恢复焦点仍重新读取。保存成功提示沿用浮层。

只缓存公开目录元信息：同一有效客户端课程目录30秒、商店配置5分钟；同时读取合并，返回独立副本，最多12项，撤销身份清空。头像、账号验证、学生课程配置/进度、会话题目、判分、奖励不缓存。后端现有静态policy/catalog已经模块内加载；本次无后端缓存服务、API变更或数据库迁移。

## 可视化衣柜与明确下一步（r29）

衣柜和商店按熊猫装扮、界面主题、答题背景分区，采用两列预览卡。原版/学士帽复用已有森林图，其他装扮复用原renderer；主题显示真实色板，背景显示实际配置。预览无交互，不领取/购买/装备，按钮维持当前卡片内相同尺寸及已确认状态。未知物品保留其他装扮分组，不静默漏掉服务端列表。

探索页空材料区别故事与听读，提供同一已配置教材的返回课程入口，不切换教材或创建会话。首页恢复复习、跳级、数感等非普通课程会话时显示对应练习类型；会话排序和ID不改，目录标题匹配同时检查kind/source_id。

探索没有材料时，主卡片直接呈现分类空状态与返回课程按钮，不再先显示占高的材料插画和介绍，避免主要恢复行动落在首屏之外。

衣柜/商店手机两列、大屏四列，卡片按钮宽度不超过180px、触摸高度至少48px，避免桌面普通动作无限拉伸。
