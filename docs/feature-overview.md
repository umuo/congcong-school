# 聪聪学堂功能总览

本文以仓库当前代码和 README 标注的 v1.8.2 为依据，介绍现有功能与已知边界。功能以 Web 为主；各端差异见下文。本文是代码和现有文档的梳理，并非本次运行或真机验收报告。

## 从选书到学习

1. 选择年级、学科和教材，沿教材单元的学习路径进入课程，也可以继续未完成的课程。
2. 阅读或收听课前知识讲解，然后作答。题目提供即时反馈和解析；课程中答错的题会重新排入队列。
3. 学完后查看结果和学习记录，之后可通过错题本继续复习。

Web 支持选择、判断、数字填空与计算、文字输入、词语排序和连线配对；部分课程提供动手操作的数感题。题干、选项和讲解等支持语音朗读，浏览器阻止自动播放时可手动播放或按页面提示继续。

### 专项学习与挑战

- **单元挑战**：有挑战课的单元，在完成该单元普通课程后解锁挑战。
- **跳级测试**：从目标单元之前的课程中抽题，正确率达到 80% 可点亮之前未完成的课程；跳级点亮不发放课程经验或宝石。
- **数感练习**：一年级数学提供数数、比较等互动练习和巩固入口；三节专项练习不扣红心。
- **错题复习**：错题进入错题本，可再次练习，并根据间隔复习逻辑安排巩固。

### 听读与故事

语文和英语提供课文听读，支持逐句或全文朗读及课本原页展示。Web 的跟读可在浏览器内录音和回放，录音不上传；需要 HTTPS 与麦克风授权，目前没有语音识别评分。课外故事提供分级阅读、插图、朗读和阅读理解题。

实现入口可参考[学习路径和挑战](../apps/web/src/components/PathMap.tsx)、[题型分发](../apps/web/src/components/question/QuestionRenderer.tsx)和[跳级测试](../apps/web/src/app/jump/JumpClient.tsx)。

## 学习管理与激励

以下以 Web 为准：

- **学习记录**：记录课程完成情况、正确率、阅读星级、经验值和连续学习情况；每日目标与本周报告展示学习进展。
- **多孩子档案**：同一浏览器可创建并切换档案，每个孩子分别保存年级、进度、错题和奖励。
- **备份**：在“我的”中手动导出或导入学习存档。记录保存在当前浏览器，清除浏览器数据可能丢失；当前没有云端账号或自动跨设备同步。
- **家长时间上限**：默认不限制，可设置 20、30、45 或 60 分钟；达到上限后暂停开始新课，不影响已经开始的课程。
- **每日任务与成就**：完成学习、复习、阅读等任务可领取宝石；达成条件可解锁成就并生成分享卡。
- **红心和奖励**：课程使用红心机制，连续答对有连击反馈；学习和任务可获得经验、宝石等，也有宝箱和每日回访奖励。
- **商店与外观**：使用宝石解锁聪聪装扮、主题和课程背景；支持亮色、暗色和跟随系统，以及语音、音效控制。
- **排行榜**：每周与 15 位本机生成的“影子同学”组成模拟联赛，存在晋级和降级；这不是与真实用户联网排名。

相关实现见[学习档案](../apps/web/src/components/LearnerProfiles.tsx)、[个人中心](../apps/web/src/app/profile/ProfileClient.tsx)和[模拟排行榜](../apps/web/src/app/league/page.tsx)。

## 平台差异

| 平台 | 当前能力与限制 |
| --- | --- |
| Web | 电脑和手机浏览器使用同一套课堂，布局随屏幕调整。学习记录保存在当前浏览器；录音需要 HTTPS 和麦克风授权。完整资源需按[安装说明](release-install.md)获取。 |
| iOS | SwiftUI 原生应用，面向 iPhone 和 iPad，包含课程、阅读、复习、任务和商店等；内置一年级数学离线种子，其他教材设计为按书从 Release 下载。可选开启本地连胜提醒。各项功能及资源与 Web 的完整一致性尚未逐项验证；[上架准备文档](../apps/mobile/APPSTORE.md)列有下载配置和真机验证待办。 |
| Android | Java/Gradle WebView 客户端，加载配置的 HTTPS Web 课堂，首次使用需要网络；学习记录保存在本机 WebView，与浏览器独立。跟读时才请求麦克风权限。目前不支持网页 `blob:` 下载，包括学习备份导出。详细限制见[安卓工程说明](android.md)。 |

页面模拟和历史 CI 检查不能替代实体设备验收；iOS、Android 的完整真机流程、音频和录音权限仍需核实。Android 客户端实际功能还取决于它所连接的 Web 站点版本。

## 内容覆盖与待办

根据 [README 的 v1.8.2 统计](../README.md#-主要特性)，内容覆盖数学、语文、英语和科学，包含六三制与五四制教材。该版本统计为 84 册教材版本（其中 14 册为旧版兼容）、4,448 个常规课时、629 个单元挑战、27,669 道常规题、6,339 道挑战题、1,311 篇或组课文及 284 篇故事。五四制各册版次与来源见[教材核对说明](five-four-2026-10-27/README.md)。这些数字是版本快照，不保证后续版本不变，也不代表内容已全部通过教师逐题审核。

项目路线图中仍待完成的内容包括全库教师签审与人工听审、云端学习记录和自动跨设备同步、教师端与班级报告、道德与法治内容，以及 iOS / Android 的完整真机验收、正式签名和应用商店发布。全库 PWA 离线预缓存也仍待补充。详见 [README 路线图](../README.md#-路线图)。
