# 云端判分规则与兼容说明

当前规则版本为 `cstf-grading-2`。TypeScript `packages/core/src/grade.ts` 与 Python `apps/api/app/learning/grading.py` 读取同一套 80 条测试向量：`packages/core/spec/grading-vectors.json`。新题目版本和新作答需记录规则版本，不能用新规则重新判定旧成绩。

## 已复现的问题与有意改变

修改前实际运行原判分函数：标准答案 `1/2`，输入 `1/3` 或 `1garbage` 均返回正确，原因是 parseFloat 只读取数字前缀。本轮改为完整语法解析，分数用有理数计算，TypeScript 使用 BigInt，Python 使用 Fraction；两端均不执行用户表达式。

- 数值必须完整匹配小数、分数、百分比及已知单位。`1/3` 不能等于 `1/2`，`12abc` 不能等于 `12`，零分母、非有限数、额外数字后缀及未识别单位不接受。
- 小数/分数/百分比按实际数值比较，例如 `1/2`、`0.5`、`50%` 等价；维持绝对误差严格小于 `10^-6`，边界本身不接受。
- 单位允许中文与常见缩写别名及省略单位；双方都写单位时必须一致，不做单位换算，不把 `3米` 与 `3厘米` 当作相等。单位集合是代码中的显式表，新增单位必须补向量。
- 原题答案是完整算式或非数值文字时仍可规范化文本比较，不尝试求解表达式。没有重写或推测题库答案。
- 选择题继续优先按完整选项内容查找，再兼容明确的位置字母；`an`、`a < b`、单字母选项内容不会被截成选项位置，用户只能提交有效位置字母。
- 连线必须是完整配对集合且键和值不能重复；不再静默覆盖重复键或忽略垃圾片段。排序维持原有顺序及大小写语义。
- 判断题双方明确识别真/假后再比较，不把未知标准答案默认当作“假”。文本题保留大小写、空白、常见标点的原容错，并统一全半角与常见 Unicode 空白。
